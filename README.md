# Мессенджер — базовый прототип

Минимальное приложение на FastAPI со статической страницей чата. Отправленные через форму сообщения добавляются только в текущую вкладку браузера. Передачи данных на сервер, WebSocket и шифрования пока нет.

## Запуск в Windows PowerShell

Откройте PowerShell в корневой папке проекта и выполните:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --reload
```

Откройте в браузере <http://127.0.0.1:8000>. Остановка сервера: `Ctrl+C` в PowerShell.

## Проверка обмена сообщениями между двумя пользователями

Откройте эти адреса в двух вкладках браузера:

- <http://127.0.0.1:8000/?user=Алиса>
- <http://127.0.0.1:8000/?user=Боб>

Дождитесь статуса «Подключено» и сообщения «ECDH успешно согласован» в обеих вкладках. В блоке согласования отображаются SHA-256 fingerprints обеих сторон; сравните их по независимому каналу. Отправьте сообщение из одной вкладки — оно появится в обеих, но пока передается без шифрования. Сообщения получают только те участники, которые уже подключены.

## Проверка ECDH

После запуска приложения откройте <http://127.0.0.1:8000/static/crypto-self-test.html>. Страница создаст две временные пары ключей P-256, экспортирует и импортирует открытые ключи в формате SPKI, вычислит секрет с обеих сторон через deriveBits и сообщит, совпали ли 32-байтовые результаты.

## Файлы

```text
app/
├── main.py                 # FastAPI и маршруты страницы и статики
└── static/
    ├── index.html          # Страница чата
    ├── style.css           # Оформление
    ├── crypto-self-test.html # Проверка Web Crypto в браузере
    └── js/
        ├── chat.js         # WebSocket, чат и согласование ключа
        ├── crypto.js       # ECDH P-256, SPKI и SHA-256 fingerprint
        └── crypto-self-test.js # Браузерный тест ECDH
requirements.txt            # FastAPI, Uvicorn и поддержка WebSocket
```
